# 幽灵糖果夜 · 幽灵躲南瓜

抖音「像塑」（Xiangsu）特效工程 —— 一个全屏躲避小游戏。

拍摄画面被隐藏，用**原生人脸横向位移**控制小幽灵左右移动，躲开从天上掉下来的软糖南瓜。

![背景](Assets/糖果月夜小镇.png)

## 玩法

- 一局 **20 秒**，**4 颗心**
- 开局 1.8 秒准备时间，受击后有 1.8 秒无敌保护
- 南瓜下落速度 `145 + 3.5t`，生成间隔 `max(0.9, 1.4 - 0.02t)`
- 成功躲开一次得 **20 分**
- 满 **100 分**进入蜘蛛阶段：蛛网以 230 速度下落、间隔 2.4 秒，命中会短暂减速 0.8 秒

控制灵敏度 850、平滑 8；丢脸时暂停。

## 双结算

| 结果 | 表现 |
|---|---|
| 失败 | 「你变成南瓜头了！」—— 弹性放大的南瓜头小幽灵 |
| 成功 | 「成功！糖果全归你啦」—— 幽灵抱住一大坨糖果 |

结算只作用于游戏角色，不是给摄像头人脸套南瓜滤镜。

## 美术

糖果月夜全屏背景，中央留干净的落物区；圆润软糖南瓜、毛绒圆蜘蛛。顶部状态板，底部两行「轻移头部」教程，全程不展示用户人脸。

## 工程

像塑工程，用像塑编辑器打开 `effect.dyehpj`。

```
Assets/          美术资源（背景、南瓜、蜘蛛等 PNG）
EffectSettings/  特效参数
EventChains/     事件链
Graph/           节点图与脚本
Icon/            图标
Record/          录制
effect.dyehpj    工程文件
DESIGN.md        完整设计稿
```

`Library/`（编辑器缓存）和 `.mcp_agent/`（运行日志）已在 `.gitignore` 中排除 —— 都是可以重建的，没必要入库。
